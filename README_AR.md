# تطبيق وِرد — مشروع أندرويد أولي

## محتويات الإصدار
- واجهة عربية تعمل داخل Android WebView.
- قسم المصحف: 114 سورة و6236 آية بالنص العثماني، فهرس وبحث باسم السورة وحفظ موضع القراءة.
- قسم الختمة: مدة مقترحة، عداد صفحات وهدف يومي.
- قسم الأذكار: إضافة وتعديل وحذف الأذكار وتغيير عدد التكرار، عداد مستقل لكل ذكر.
- حفظ محلي عبر `localStorage` داخل التطبيق.

## مصدر النص القرآني
النص مضمّن من ملف `qurantext-uthmani.def` في حزمة `quran` الموزعة مع TeX Live. أسماء السور العربية مأخوذة من بيانات الحزمة، ويذكر ملف `quran.sty` أنها من بيانات مشروع تنزيل. راجع:
- `app/src/main/assets/QURAN_SOURCE_NOTICE.txt`
- `app/src/main/assets/LPPL_LICENSE.txt`

تم التحقق برمجياً من وجود 114 سورة و6236 آية وتطابق أعداد الآيات القياسية لكل سورة. هذا تحقق بنيوي، وليس مقابلة حرفية مستقلة مع مصحف مطبوع أو تنزيل حديث من Tanzil. ينبغي إجراء مراجعة نصية مستقلة قبل النشر العام. النص القرآني غير قابل للتحرير من واجهة التطبيق.

## بناء APK
لم يتم إنشاء APK في بيئة العمل الحالية لعدم توفر Android SDK أو `android.jar` أو Gradle executable.
1. ثبّت Android Studio على جهاز كمبيوتر.
2. افتح مجلد المشروع `WirdAndroid`.
3. انتظر Gradle Sync وتنزيل أدوات Android المطلوبة.
4. اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. الملف الناتج عادة: `app/build/outputs/apk/debug/app-debug.apk`.

ويمكنك بدلاً من ذلك رفع المشروع إلى مستودع GitHub ثم تشغيل Workflow باسم **Build Android APK** من تبويب Actions؛ سيبني ملف APK ويرفعه كـ Artifact باسم `wird-debug-apk`.
